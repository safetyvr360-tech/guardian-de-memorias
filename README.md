# Guardián de Memorias

Recorrido virtual gamificado en 360° por Puerto Colombia, Atlántico. Marina y el Capitán Azulín guían al visitante por cinco lugares reales: La Plaza de los Recuerdos, El Faro de los Sueños, El Escudo Verde del Caribe, La Alerta en la Desembocadura y El Santuario del Manglar. En cada escena se buscan objetos, se responden preguntas y se gana una insignia para el Pasaporte del Guardián; al final se presta el Juramento del Guardián y se recibe un certificado.

Proyecto apoyado por el Portafolio de Estímulos para el Arte y la Cultura ProgreArte, Secretaría de Cultura y Patrimonio, Alcaldía Municipal de Puerto Colombia.

Realizado por Ultramedia360 con 3DVista Virtual Tour Pro.

Para verlo, abre `index.html` en un navegador o visita la página publicada de este repositorio.
